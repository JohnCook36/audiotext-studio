# AudioText Studio — Android

Отдельное мобильное приложение в папке `mobile/`. Windows-версия в корне репозитория не меняется.

## Что реализовано в первой сборке
- Android 8+, 64-битный ARM (arm64-v8a);
- импорт аудио и видео через системный выбор файла;
- извлечение звука в WAV, а AAC-аудиодорожек — в M4A без перекодирования;
- локальное распознавание с помощью whisper.cpp (мультиязычные tiny/base);
- экспорт TXT с временными метками и субтитров SRT;
- сохранение результатов в каталог приложения и отправка через стандартное меню «Поделиться»;
- загрузка моделей Whisper один раз по HTTPS, затем распознавание без интернета.

## Где скачать APK
Открой [Build Android APK](../../actions/workflows/build-android.yml), выбери успешную сборку и скачай **AudioTextStudio-Android-APK**. В ZIP находится `app-debug.apk`: тестовая версия, подписанная отладочным ключом сборочной машины.

## Как собирается приложение
В CI применяется Java 17, Android SDK 35, Gradle 8.9 и Android NDK 26.3.11579264. Код whisper.cpp скачивается из upstream-репозитория с закреплённым тегом `v1.7.6`. Поэтому GitHub не хранит стороннюю библиотеку в папке проекта.

## Ограничения первой версии
- Длительная обработка возможна только при открытом приложении; при сворачивании Android может остановить процесс.
- В первой версии WAV производится путём декодирования и ресемплинга аудиодорожки до PCM 16 кГц, моно. Для AAC можно сохранить исходную дорожку в M4A.
- MP3 кодирование пока не добавлено; программа не извлекает защищённое DRM видео.
- Распознавание разбивается на куски по 25 секунд и может давать неточные границы фраз.
- Телефон может заметно нагреваться и разряжаться при локальном распознавании; скорость зависит от CPU и длительности записи.
- iOS и публикация в магазинах приложений пока не реализованы.

Права доступа к хранилищу Android не запрашиваются: доступ выдаётся только к выбранному пользователем файлу. Записи и расшифровки не отправляются разработчику или на сервер.
