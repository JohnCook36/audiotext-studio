# Как получить AudioTextStudio_Setup.exe на GitHub

## Один раз: создайте репозиторий

1. Откройте <https://github.com/new?name=audiotext-studio> под аккаунтом **JohnCook36**.
2. Назовите репозиторий `audiotext-studio`. Выберите Private (для личного использования) либо Public (если хотите открытый код).
3. **Не создавайте на сайте** README, .gitignore или лицензию: все файлы уже есть в проекте.
4. Распакуйте архив проекта в отдельную папку на Windows 11 и запустите `PUBLISH_TO_GITHUB.cmd`. Требуется Git for Windows, установленный заранее. При запросе войдите в свой GitHub через браузер.

## Готовый установщик — без локальной сборки

1. Откройте <https://github.com/JohnCook36/audiotext-studio/actions>.
2. Найдите последний успешный запуск **Build Windows installer**.
3. Внизу страницы запуска в разделе **Artifacts** скачайте `AudioTextStudio-Windows-Installer`.
4. Распакуйте загруженный ZIP и откройте `AudioTextStudio_Setup_1.1.0.exe`.

Каждый пуш в ветку main запускает сборку на GitHub Windows runner. Также workflow поддерживает **Run workflow**. Сборка может быть долгой, но ваш компьютер не участвует.

## Постоянная ссылка через Releases

Для выпуска версии `v1.1.0` создайте тег через Git:

```
git tag v1.1.0
git push origin v1.1.0
```

После успешной сборки установщик будет прикреплён к релизу в GitHub **Releases**. Для следующих версий используйте новые теги, например `v1.0.1`, и обновляйте исходный код по необходимости.

**Важно:** установщик не имеет цифровой подписи. Windows SmartScreen может предупреждать о неизвестном издателе; не отключайте антивирус ради запуска. Первая загрузка модели Whisper требует доступа к интернету, обработка ваших аудио-/видео файлов выполняется локально.
